# Greenden-tailwind
Greenden is a responsive plant website built using Tailwind CSS, featuring a clean, modern, and mobile-friendly design.
🌿 Greenden – Plant Website

Greenden is a fully responsive plant-based website created using HTML and Tailwind CSS. This project focuses on a clean and modern UI with a mobile-first design approach. Tailwind utility classes are used to build fast, reusable, and well-structured layouts. The website includes sections like Home, Products, and Contact, making it suitable for beginners to showcase frontend skills.

🚀 Technologies Used

HTML5

Tailwind CSS

✨ Features

Fully responsive design

Clean and modern UI

Mobile-first layout

Fast styling with Tailwind CSS
